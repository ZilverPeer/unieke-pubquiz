# Self-hosted WordPress, not WordPress.com

We need WooCommerce (with Mollie and other plugins) and direct CLI/WP-CLI access so the backend and Claude Code can manage the storefront programmatically. WordPress.com only unlocks WooCommerce on its Commerce plan and SSH/WP-CLI access on Business and up, both expensive and still platform-constrained. We're starting the storefront clean (no existing WordPress account to migrate), so we chose self-hosted WordPress (own VPS/hosting) for full plugin freedom and CLI access, accepting the added maintenance burden (updates, security) ourselves.
