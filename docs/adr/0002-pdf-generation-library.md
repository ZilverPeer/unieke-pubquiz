# PDF generation with @react-pdf/renderer, not pdf-lib

We need to generate multi-page quiz PDFs — plain text/answer pages and a styled, flexbox-like grid layout for the Picture Round (a numbered image grid with a background texture and branding elements, design still evolving). We chose `@react-pdf/renderer` over `pdf-lib`: it lets us describe pages as React components with CSS-flexbox-style `StyleSheet` layout, which maps directly onto the grid-based Picture Round design and keeps iteration fast while the visual design is still being figured out. `pdf-lib` is lower-level (byte-level PDF construction, manual x/y coordinate placement for every element) — closer to the old Python `reportlab` approach we're moving away from, and much more code to maintain as the design changes. Both run in plain Node.js with no headless-browser dependency, so this doesn't affect the Vercel Fluid Compute deployment target.
