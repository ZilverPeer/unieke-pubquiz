Shared domain types (`Locale`, `QuizMode`, `ItemKind`, `Difficulty`, `RequestedDifficulty`, `QuizRequest`, `PoolItem`, `Composition`, `GenerationFailure`, `CompositionRecord`), the render input types (`QuizContent`, `RoundContent`, `ItemContent` in `content.ts`), the per-Locale message catalogs and `message()` lookup helper, and the in-memory pool fixture builder (`buildPoolFixture`) and the render input fixture builder (`buildQuizContentFixture`) used by tests. This module imports nothing from any other `src` module — every other module may import from it.
